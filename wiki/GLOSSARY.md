# Glossary

These are working definitions for this corpus.
Legal definitions can differ by jurisdiction.

| Term | Meaning here |
| --- | --- |
| AI | A broad class of systems that perform tasks associated with intelligence. |
| LLM | A large language model. A model alone does not hold public authority. |
| Model | Trained parameters and inference methods that produce outputs. |
| Agent | A system that uses a model, tools, permissions, and a task loop. |
| Open weights | Model parameters are available under specified terms. This does not always mean open-source software. |
| Frontier model | A model near the leading edge of specified capabilities at a stated date. |
| AGI | Artificial general intelligence. Each source can define this differently. |
| Superintelligence | Capabilities far above human performance across many cognitive tasks, under the source's definition. |
| Alignment | The problem of making a system's behavior fit intended human goals and constraints. |
| Control failure | A system acts beyond intended human control. The cause can be error, misuse, or goal conflict. |
| Misuse | A human uses a system for a harmful purpose. |
| Rogue model | An ambiguous phrase. Specify the operator, permissions, behavior, and type of control failure. |
| Attribution | A judgment about the actor responsible for an event. Technical origin alone is insufficient. |
| State authorization | Approval by the relevant state authority. It is separate from nationality or server location. |
| Compute | Computing resources. Capacity, availability, efficiency, and access are separate variables. |
| Training | The process used to change model parameters. |
| Inference | Use of a trained model to produce outputs. |
| Fab | A semiconductor fabrication plant. |
| Foundry | A firm that manufactures chip designs for customers. |
| HBM | High-bandwidth memory used with some advanced processors. |
| Advanced packaging | Processes that connect chips and memory in a package. |
| EUV | Extreme ultraviolet lithography used in some advanced chip manufacturing. |
| EDA | Electronic design automation software used to design chips. |
| Chokepoint | A dependency with few near-term substitutes. Its strength can change. |
| Dual use | A capability has both civilian and military uses. |
| NC3 | Nuclear command, control, and communications. |
| Entanglement | Nuclear and conventional systems share assets, functions, or signals. |
| Deterrence | An effort to prevent an action by changing expected costs or benefits. |
| Compellence | An effort to make another actor take or stop an action. |
| Preventive war | War motivated by a feared future shift in power. |
| Preemption | Action against an attack believed to be imminent. |
| Escalation | A change that increases conflict severity, scope, or risk. |
| Quarantine | A source's label for selective maritime controls. Record the actual conduct and legal claims. |
| Blockade | A source's label for sustained denial of maritime access. Do not infer legality from the label. |
| Inventory | All counted warheads under the source's definition, which can include retired weapons. |
| Stockpile | Warheads retained for possible military use under the source's definition. |
| Deployed | Warheads assigned to deployed forces under the source's definition. |
| State variable | A defined feature of the game world. |
| Belief | An actor's view of a state variable. It can be wrong. |
| Guard | A condition that must hold before a game transition can occur. |
| Transition | A permitted change in game state after an event or choice. |
| Signpost | An observable development that tests a scenario assumption. |
| Off-ramp | A decision or event that can stop or reduce escalation. |

See the [method](METHOD.md) for evidence labels.
