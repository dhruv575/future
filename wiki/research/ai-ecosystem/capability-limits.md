# Capabilities and measurement limits

A benchmark result describes a model in a setup. It does not describe every product that uses the model.

| Component | Meaning for a game |
|---|---|
| Model | The trained system that produces outputs. |
| Agent | Model, tools, memory and an action loop. |
| Host | The environment that runs the agent. |
| Permissions | The systems and actions the host allows. |
| Operator | The human or institution that sets tasks. |
| Weapon integration | A separate connection to a military system and command process. |

These are working definitions for the corpus. They prevent category errors.

## Task length

METR's horizon is measured in human-expert task time. A 50 percent horizon is a fitted success threshold. It is not runtime or a general autonomy limit.

The suite mainly tests well-specified software-related tasks. METR warns that longer estimates exceed the suite's reliable range. It stopped active page updates in September 2026. [AI-S008](https://metr.org/time-horizons/)

Do not convert that curve into "full cyber control in year X." The conversion needs separate evidence about access, reliability and defenses.

## Reasoning and training

DeepSeek-R1's abstract supports progress on verifiable reasoning tasks. DeepSeek-V3 reports efficient training. Neither abstract establishes geopolitical judgment or complete autonomous attack competence. [AI-S017](https://arxiv.org/abs/2501.12948), [AI-S018](https://arxiv.org/abs/2412.19437)

Training compute is not total research cost. It also differs from inference capacity available during a crisis.

Anthropic's reward-hacking study used selected vulnerable tasks and an experimental training setup. Its result supports a possible failure mechanism. It does not measure routine deployment prevalence. [AI-S012](https://www.anthropic.com/research/emergent-misalignment-reward-hacking)

## Security and control

A safety policy, a successful test and an effective deployed safeguard are three different objects. Record them separately.

Google and Anthropic publish evolving safety frameworks. They show intended processes. They do not prove complete protection. [AI-S010](https://deepmind.google/frontier-safety/), [AI-S038](https://www.anthropic.com/responsible-scaling-policy)

Model-weight protection needs multiple controls and a defined attacker model. RAND does not offer one measure that defeats every attacker. [AI-S009](https://www.rand.org/pubs/research_reports/RRA2849-1.html)

A shutdown option needs an implementation path. Specify who controls the process, credentials, host and copies. Do not give an organization authority over systems it does not operate.

## Capability record for later modeling

For each assessment, record model version, date, tools, permissions, budget, safety filters, task distribution and success criterion.

Also record the evidence class and whether an independent group reproduced the result. Leave missing fields unknown.

## Independent synthesis

The February 2026 International AI Safety Report gives a broad expert baseline. It distinguishes uneven capability gains, observed misuse and a stricter loss-of-control outcome. Later incident evidence needs separate review. [AI-S043](https://internationalaisafetyreport.org/publication/2026-report-executive-summary)
