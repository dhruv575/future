# Suspected model theft creates a strategic alarm

Record: AI-X003. Status: hypothesis. Horizon: 2026-2035.

Trigger: A lab reports possible unauthorized access to a valuable model or related research.

This dossier is original scenario analysis. Sources establish components, not the full causal chain. No branch has an assigned probability.

The opening alert should name the uncertain asset. "Model theft" is too broad for a state transition. Record actual weights, training code, data, research notes and generated outputs as separate classes.

RAND studies protection against attackers with different resources. Its report supports a threat-model structure. It does not establish that any lab is safe against every state. See [AI-S009](https://www.rand.org/pubs/research_reports/RRA2849-1.html).

OpenAI's September 2026 report concerns alleged adversarial distillation. It attributes a core activity cluster to people associated with Moonshot AI. It does not establish Chinese state direction or actual theft of weights. See [AI-S037](https://openai.com/index/disrupting-a-coordinated-model-distillation-campaign/).

Players need to distinguish a verified technical loss from an estimate of its value. A model may work differently outside the developer's service. A copied checkpoint can lack surrounding tools, updates or safeguards. The magnitude of that gap needs its own evidence.

For a cloud-provider player, useful choices concern access review, evidence retention and service continuity. For a lab leader, choices concern containment, notification and disclosure. A government response is an external branch with separate authority.

The game should allow a false alarm or a smaller loss than first reported. It should also allow delayed discovery of a larger loss. These are competing hypotheses, not equal-probability outcomes.

Do not use a fixed "theft equals war" rule. Add intermediate beliefs: confidence in the loss, confidence in attribution, expected capability change and perceived urgency. Test how decisions change when each belief is wrong.

## Branch choices

- **Classify the asset and verify whether it was copied.** Condition: Forensic evidence is available. Result: The case separates weight theft, output collection and ordinary research exchange.
- **Secure remaining copies and audit partner access.** Condition: The owner and hosts cooperate. Result: Further loss can be limited; already distributed copies may remain.
- **Claim that a rival has gained decisive strategic capability.** Condition: Leaders infer downstream power from incomplete theft evidence. Result: Pressure for emergency restrictions or retaliation can rise.
- **Negotiate verification and a bounded response.** Condition: Enough evidence can be shared without exposing the asset. Result: The dispute can remain a security and diplomatic issue.

## Limits

- No cited source proves that a specific US or Chinese frontier model's weights were stolen in the described future event.
- Distillation, leaked outputs, stolen code and copied weights are different assets and acts.
- A transferred model still requires a usable runtime, compute and operating access.
- No source maps one model loss directly to strategic dominance.
